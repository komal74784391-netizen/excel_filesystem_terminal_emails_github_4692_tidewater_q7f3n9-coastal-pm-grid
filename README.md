# Coastal PM2.5 Grid, 2019-2026

Reproducibility package for the coastal PM2.5 station grid reanalysis for the Tidewater Observing Network.

## Repository Status

**Released.** Version 1.4.0 (2026-05-14) is published. The scripts, metadata and derived products in this repository are the released artefact for this dataset.

## Layout

- `src/` — processing and QA/QC code
- `data/` — station metadata and product index
- `notebooks/` — validation notebooks
- `tests/` — regression checks
